# 游戏入库前端 —— 使用说明

## 怎么用（3 步）

### 1. 打开前端

**桌面模式**：应用菜单里找 **「游戏入库」**，双击

**或者**终端里跑：
```bash
~/steam-toolkit/start-webui.sh
```
会打开 http://127.0.0.1:8917/

### 2. 输入 AppID → 点「搜索」

AppID 从 Steam 商店页面地址里拿，例如：
```
store.steampowered.com/app/4012810/    ← 中间这个数字
```

**搜索结果有两种**：

| 结果 | 显示 |
|---|---|
| **搜到** | 游戏名 + depot 数量 + 数据来源 + 「入库」按钮 |
| **搜不到** | 红字提示「没有这个游戏的数据」 |

### 3. 点「入库」→ 重启 Steam

入库完成后：
1. **完全退出 Steam**（托盘也退）
2. 重新打开 Steam（`~/.local/share/SLSsteam/path/steam` 或双击桌面图标）
3. 库里找到这个游戏 → 点「安装」→ 自动下载

---

## ⚠️ 为什么必须重启 Steam

```
depot 密钥只在 Steam【启动时】从 config.vdf 读取
→ 写入后不重启，Steam 不知道有新密钥 → 会报"内容加密"
```

## 数据源说明（三个库自动回退）

| 库 | 条目数 | 作用 |
|---|---|---|
| **Sudama** | 239,946 | 主密钥库（覆盖最新游戏） |
| **社区 depotkeys** | 288,381 | 补充 |
| **ManifestHub3** | 62,000+ 分支 | 提供清单文件 + Lua + 游戏名 |
| **SteamUnlock API** | — | 提供 depot 列表 + 清单 GID |

**搜索时会依次查这三个库**，谁有就用谁。

---

## 搜不到怎么办

说明三个库都还没收录。可能原因：

1. **游戏太新** —— 密钥需要有人先拥有才能提取，等社区更新（通常几天到几周）
2. **游戏太冷门**
3. **AppID 输错了**

**没有别的办法** —— 密钥不是算出来的，是从拥有游戏的人那里提取的。

---

## 卸载已入库的游戏

前端目前只做入库。要卸载，终端里跑：

```bash
cd ~/steam-toolkit
python3 -c "
import webui_core
r = webui_core.uninstall(<AppID>)
print(r['message'])
for s in r['steps']: print(' ', s)
"
```
然后重启 Steam。

**注意**：卸载只删 Lua 和 AppIds 条目，**保留密钥**（避免误删你正版游戏的密钥）。

## 安全设计

| 机制 | 说明 |
|---|---|
| **自动备份** | 每次写操作前备份到 `backup/webui/` |
| **只增不改** | 不改动已有的密钥条目（同一个 depot 才覆盖） |
| **原子写入** | 临时文件 + rename，避免写一半断电损坏 |
| **写后校验** | 立刻用 VDF 解析器验证文件完整性 |
| **并发锁** | 同时只允许一个写操作 |
| **本机绑定** | 只监听 127.0.0.1，局域网访问不到 |
| **不自动重启** | Steam 重启由用户决定 |

## 游戏模式说明

**注入在游戏模式下已经生效**（不需要额外设置）：

```
✓ steam.desktop → ~/.local/share/SLSsteam/path/steam（带 LD_AUDIT 注入）
✓ 游戏模式启动的 Steam 进程确认有 LD_AUDIT
✓ 启动器日志记录 "带 SLSsteam-Plus 注入启动"
```

**但前端只能在桌面模式用**（游戏模式下没有浏览器）。

**典型用法**：
```
桌面模式 → 打开前端 → 入库 → 重启 Steam → 切回游戏模式玩
```

## 故障排查

| 症状 | 原因 | 处理 |
|---|---|---|
| 前端打不开 | 服务没启动 | `~/steam-toolkit/start-webui.sh` |
| 入库后游戏不显示 | 没重启 Steam | 完全退出再打开 |
| 点安装报"内容加密" | 密钥没读到 | 重启 Steam；或重新入库 |
| 点安装报"无互联网连接" | 有坏的安装记录 | 删 `steamapps/appmanifest_<appid>.acf` 再重试 |
| Steam 打不开 | 注入库损坏 | `~/.local/bin/steam-noinject` |
| 想完全回滚 | — | 见 [恢复手册](恢复手册.md) |
