# SLSsteam-Plus 编译说明（SteamOS）

## 为什么需要自己编译
原版发布包（v0.2.2）在本机 Steam 上会失败：
```
Diagnostics: pattern summary found=41 missing=4 total=45
Failed to find all patterns! Aborting...
```
4 条特征码因 Steam 更新失效，而 Plus 的设计是"缺一条就整体放弃"。

## 构建环境（已搭好，可复用）

```bash
# 环境脚本（每个新 shell 都要 source）
source ~/buildenv.sh

# 它设置
#   PATH=/home/deck/buildtools/wrappers          ← cmake/pkg-config 包装器
#   C_INCLUDE_PATH=/home/deck/buildtools/usr/include  ← 32位 glibc + openssl + curl 头
```

### buildtools 里有什么（从 Arch 仓库提取，不需要 sudo）
| 包 | 用途 |
|---|---|
| cmake 4.4.4 + jsoncpp/rhash/libuv/cppdap | 构建系统 |
| pkgconf 3.0.7 | 依赖查询 |
| lib32-glibc | ★ **32 位开发头文件**（SteamOS 完全没有） |
| openssl 3.6.5 / curl 8.22.0 | 开发头文件 |

## 编译步骤

```bash
source ~/buildenv.sh
cd ~/slsplus-build
make -j16 bin/SLSsteam.so bin/library-inject.so
cp bin/SLSsteam.so bin/library-inject.so ~/.local/share/SLSsteam/
```

## 对源码做的修改

### 1. `res/patterns.toml` —— 4 条特征码标记 optional
```toml
[Patterns.steamui."CUpdateManager::MarkAppChange"]      → optional = true
[Patterns.steamclient."CSteamMatchmakingServers::RequestInternetServerList"] → optional = true
[Patterns.steamclient."IClientRemoteStorage::RunIPCFrame"] → optional = true
[Patterns.steamclient."IClientUserStats::RunIPCFrame"]     → optional = true
```
效果：`47/47 全部匹配`，不再中止加载。

### 2. `Makefile` —— GCC 15 / SteamOS 兼容
```make
# libmem 的 cmake 参数加
-include cstdint -D_GNU_SOURCE     # keystone 的 LLVM 需要
# 链接参数改（Arch 的 libcurl.pc 声明了系统没有的依赖）
LDFLAGS += -lcurl -lssl -lcrypto   # 原来是 pkg-config --libs libcurl
```

### 3. `src/sdk/protobufs/slssteam_messages.proto` —— 加了 depot 密钥消息定义
（为将来做网络层注入预留，目前方案不需要）
```proto
message CMsgClientGetDepotDecryptionKey { depot_id=1; app_id=2; }
message CMsgClientGetDepotDecryptionKeyResponse { eresult=1; depot_id=2; depot_encryption_key=3; }
```

### 4. `src/main.cpp` 的启动检查（**未改**，靠 optional 解决）
```cpp
const bool patternsFound = Patterns::init();
if (!patternsFound) { g_pLog->warn("Failed to find all patterns! Aborting..."); return; }
```

## 重新编译后必须
```bash
cp ~/slsplus-build/bin/SLSsteam.so ~/.local/share/SLSsteam/
# 重启 Steam
```
