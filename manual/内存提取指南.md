# 提取解密后的密钥库（Windows 内存转储）

## 原理

```
GUI.dll 被注入进 Steam → 运行时解密 .kA; 段（1.7MB）
                        → 里面是注入逻辑 + 密钥库
     ↓
密钥在 steam.exe 的内存里（已解密）
     ↓
转储 steam.exe 的内存 → 搜到密钥
```

## 方法 1：用 Process Hacker（推荐，免费开源）

### 1.1 下载
https://processhacker.sourceforge.io/ → 下载 → 安装

### 1.2 操作
1. 用 **SteamUnlock** 启动 Steam（让工具注入）
2. 打开 **Process Hacker**
3. 找到 **steam.exe** → 右键 → **Properties**
4. 切到 **Memory** 标签页
5. 找到 **GUI.dll** 或那个 **1.7MB 的私有提交区域**
6. 右键 → **Save to file**（保存为 `dump.bin`）

### 1.3 或者更简单：直接搜字符串
1. Process Hacker → steam.exe → 右键 → **Miscellaneous** → **Search Memory**
2. 搜 **`"Keys"`** 或 **`applist`** 或 **`depot_encryption`**
3. 找到后看周围的内存

## 方法 2：用 Cheat Engine（更灵活）

### 2.1 下载
https://cheatengine.org/

### 2.2 操作
1. 用 SteamUnlock 启动 Steam
2. Cheat Engine → 打开进程 → `steam.exe`
3. 勾选 **Enable Speedhack** 下方的 **Memory View**
4. 在 Memory View 里用 **Ctrl+G** 跳到 GUI.dll 的基址
   （基址在 Process Hacker 里能看到，或在 Cheat Engine 的 **Memory Regions** 里找）
5. 找到 `.kA;` 段对应的内存区域（大小 0x19f400 = 1700864 字节）
6. **右键 → Save memory region to file**

### 2.3 关键：确认解密成功
在内存里搜这些字符串（Ctrl+F）：
- `Keys`
- `depot`
- `DecryptionKey`
- `applist`

**如果搜到了明文 → 解密成功 → 保存下来发我**

## 方法 3（最简单）：抓 config.vdf 的变化

**如果我们运气好，工具在下载新游戏时会把密钥写进某个文件：**

1. 用 SteamUnlock 入库一个**未授权**的游戏并开始下载
2. 立刻跑：
   ```cmd
   findstr /s /i /c:"DecryptionKey" "F:\steam\config\*.json" "F:\steam\config\*.vdf"
   ```
3. 看有没有新东西

## 我要的是什么

**任意一个能让我看到"32 字节密钥"和"depot id"配对的地方。**

最理想的产物：
- `dump.bin`（内存转储，1-2MB）
- 或者一张截图：内存里 `{"Keys": {...}}` 的样子

## 为什么这一步值得做

```
成功 → 拿到所有游戏的密钥 → 所有游戏都能下（包括命运石之门）
失败 → 确认密钥是 Valve 发的 → 转而做网络层构造
```

**两条路都是往前走，不会白做。**
