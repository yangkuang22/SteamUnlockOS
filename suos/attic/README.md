## depot.py（586 行）

**功能**：Steam depot 清单解析 + 文件块解密（AES-256-CBC + zstd/LZMA）

**为什么没用上**：这是我们早期的"第三方直接下载"路线的实现 ——
自己从 Valve CDN 拉 chunk、解密、解压，完全绕开 Steam 客户端。

**现在的方案**：走 SLSsteam-Plus（构造所有权，让 Steam 自己下载），
所以这条路不需要了。

**将来什么时候有用**：
- 如果 SLSsteam 上游停止维护，无法适配新 Steam
- 如果想做"下载后手动安装"的功能
- 如果想在没装 Steam 的环境里准备游戏文件

**状态**：未验证是否与当前 Steam 的 manifest 格式兼容（实现时是 2026-10-02，
基于 appid 4012810 的清单实测）。要用之前先测。
